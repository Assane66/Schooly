# Parcours d’inscription établissement

Le parcours directeur Schooly est composé de quatre écrans successifs, afin de séparer clairement les informations de la personne de celles de l’établissement.

| Étape | Contenu | Résultat attendu |
|---|---|---|
| 1. Directeur | Prénom, nom, téléphone, e-mail, adresse et localisation personnelle | Création du compte personnel du directeur |
| 2. Établissement | Nom, adresse, localisation, téléphone et e-mail professionnel facultatifs | Préparation de la fiche de l’école |
| 3. Classes | Élémentaire, collège, lycée ; liste de classes générée puis modifiable | Structure initiale sans université |
| 4. Accès | Mot de passe et récapitulatif | Envoi du lien de confirmation vers Schooly |

Après confirmation de l’adresse e-mail, Schooly lit les informations enregistrées dans le profil d’authentification, crée l’établissement et les classes prévues, puis dirige le directeur vers son espace de gestion.
